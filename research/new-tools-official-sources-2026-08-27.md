# 신규 도구 공식 출처 조사

## Google Stitch
- 공식 URL: https://stitch.withgoogle.com/
- 공식 페이지 설명: 모바일 및 웹 애플리케이션용 UI 디자인 생성 도구.
- 페이지 FAQ/기능 영역에서 확인된 항목: App/Web 모드, 텍스트 기반 디자인 생성, Figma export FAQ, working code 생성 FAQ, interactive multi-screen flows FAQ, MCP integration FAQ.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## Google Flow
- 공식 URL: https://labs.google/fx/tools/flow
- 공식 페이지 설명: 실제 또는 생성된 입력 참조로 영상을 만들고 편집하는 도구.
- 공식 페이지에서 확인된 기능: Google Flow 안에서 Gemini Omni와 Veo를 사용해 영상 제작·편집; Veo는 창작 제어, 네이티브 오디오, 물리·사실성·프롬프트 준수에 초점을 둠.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## 추가 조사 필요
- NotebookLM, Google AI Studio, Google Antigravity, Pomelli, Illuminate, TextFX, Opal, MusicFX의 공식 현재 URL·가격 상태·서비스 상태를 각 공식 페이지에서 추가 확인해야 함.
- 카탈로그 편입 시 원문 확인일과 가격 확인 상태를 별도 필드로 기록하고, 확인되지 않은 가격은 단정하지 않음.

## Google Illuminate
- 공식 URL: https://illuminate.google.com/explore
- 공식 페이지 설명: 콘텐츠를 학습 선호도에 맞춰 AI 생성 오디오 토론으로 변환하는 실험 기술.
- 현재 상태: 페이지에 waitlist와 sign-in 안내가 표시되며, 컴퓨터 과학 주제에 최적화되어 있고 토론과 음성은 AI 생성이라고 명시됨.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## Google Opal
- 공식 URL: https://opal.google/
- 공식 검색 결과 설명: 자연어로 AI 미니앱을 만들고, 편집하고, 공유하는 실험 도구.
- 현재 상태: 공식 페이지는 동적 로딩 화면으로 확인되었으므로 세부 기능·가격은 공개 안내를 추가 확인할 필요가 있음.
- 조사 방식: 공식 페이지 브라우저 확인 및 공식 검색 결과, 2026-08-27.

## Google TextFX
- 공식 URL: https://textfx.withgoogle.com/
- 공식 페이지 설명: 랩의 언어·작사 기법에서 영감을 받은 글쓰기 창작 도구 모음. 글을 대신 완성하기보다 창작 가능성을 넓히고 텍스트를 새롭게 보도록 돕는다고 안내함.
- 출처·기술 맥락: Google AI Studio와 Gemini API 협업으로 만들어졌으며, 공식 페이지는 사용자가 창의성과 글쓰기 역량을 직접 가져와야 한다고 명시함.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## Google Flow Music / MusicFX 계열
- 현재 공식 URL: https://www.flowmusic.app/
- 공식 페이지 설명: Producer와 대화하며 곡을 만들고 편집하는 음악 생성 서비스.
- 공식 페이지에서 확인된 기능: 가사 브레인스토밍, 곡 공동 제작, 음악 리믹스, 정식 곡 생성·게시·공유, Veo 기반 AI 뮤직비디오, 오디오 효과, stem split, vibe-code 공간.
- 가격 상태: 공식 페이지에 “Free to start · No credit card required”가 표시됨. 일일 크레딧도 언급됨.
- 명칭 주의: 사용자가 말한 MusicFX는 현재 공개 음악 제품 페이지에서 Flow Music으로 표시되므로, 카탈로그에는 “MusicFX / Google Flow Music”으로 연결하고 명칭 변경을 설명하는 것이 안전함.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## Google AI Studio
- 공식 URL: https://aistudio.google.com/welcome
- 공식 페이지 설명: Gemini·Veo·Nano Banana 등으로 프롬프트에서 프로덕션까지 이어가는 개발·창작 환경.
- 공식 페이지에서 확인된 기능: Gemini 프롬프트 실험, Veo 영상, Gemini TTS, Live, Omni, Lyria 음악, API key 관리, GenAI SDK, Interactions API, 도구 호출, 앱 갤러리·자연어 앱 생성.
- 가격 확인: 공식 페이지에 Pricing 링크가 있으므로 카탈로그의 현재 레코드는 가격 페이지 링크를 함께 제공하는 것이 적절함. 무료 여부는 모델·API 사용량에 따라 달라질 수 있어 단정하지 않음.
- 조사 방식: 공식 페이지 브라우저 확인, 2026-08-27.

## NotebookLM / Gemini Notebook
- 현재 계획 URL: https://notebook.google/plans
- 공식 페이지에서 확인된 최신 명칭: Gemini Notebook. 기존 NotebookLM 서비스와의 관계는 공식 FAQ에서 확인 대상으로 안내됨.
- 공식 계획 페이지에서 확인된 플랜: Standard, Plus, Pro, Ultra. Standard는 오디오·비디오 개요와 Gemini 모델 접근, notebook당 최대 50개 항목을 안내하며, 상위 플랜은 생성 한도와 모델 접근 수준이 증가함.
- 기존 제품 URL: https://notebooklm.google.com/
- 카탈로그에는 “NotebookLM (현재 Gemini Notebook)”처럼 병기하고, 가격은 고정 숫자 대신 공식 계획 페이지 링크와 플랜별 변동 가능성을 표시하는 것이 안전함.
- 조사 방식: 공식 계획 페이지 브라우저 확인, 2026-08-27.
