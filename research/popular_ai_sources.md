# 대중적인 AI 서비스 정제 조사

## 조사 기준

현재 원문 카탈로그는 GitHub 기반 앱 모음이라 macOS 래퍼·모델·개발 프로젝트가 실제 AI 서비스와 같은 목록에 섞여 있다. 이번 정제에서는 일반 사용자가 바로 방문해 결과물을 만들 수 있는 서비스, 기존 업무 앱에 AI가 핵심 기능으로 포함된 서비스, 반복 업무·리서치·창작·코딩에 널리 사용되는 서비스를 우선한다. 단순 모델명, GitHub 저장소, OS 전용 래퍼, 라이브러리·프레임워크는 일반 도구 목록에서 제외하고 별도 기술/원문 레이어로 보존한다.

## 적용 원칙

정제 카탈로그는 각 레코드에 서비스명, 공식 URL, 대표 용도, 사용자 카테고리, 가격 상태, 대중성/검증 상태, 연결 작업 태그를 포함한다. 원문 레코드의 이름이나 설명을 그대로 반복하지 않고, 일반 사용자가 이해할 수 있는 한 문장 설명을 작성한다. 같은 서비스의 앱 래퍼·모델명·공식 서비스는 하나의 서비스 레코드로 병합하고, 기술·모델·오픈소스 기록은 AI 도구 목록에서 분리한다.
