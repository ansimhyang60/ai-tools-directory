The source scan found six `VITE_` names:

| Variable | Usage / source | Required for static + archive fallback path |
|---|---|---|
| `VITE_ANALYTICS_ENDPOINT` | Analytics configuration injected by the platform | No; analytics is optional |
| `VITE_ANALYTICS_WEBSITE_ID` | Analytics site identifier injected by the platform | No; analytics is optional |
| `VITE_APP_ID` | Manus OAuth client configuration | No for public browsing; required only for Manus login |
| `VITE_FRONTEND_FORGE_API_KEY` | Manus frontend Forge integration | No for the current directory and fallback archive |
| `VITE_FRONTEND_FORGE_API_URL` | Manus frontend Forge endpoint | No for the current directory and fallback archive |
| `VITE_OAUTH_PORTAL_URL` | Manus OAuth login portal | No for public browsing; required only for Manus login |

The current public browsing path does not require a user-supplied Vercel secret. Auth and Forge integrations remain platform-provided optional capabilities. No new secret was requested or saved because the user explicitly wanted an environment-variable-free automatic archive path and the site renders without custom credentials.
